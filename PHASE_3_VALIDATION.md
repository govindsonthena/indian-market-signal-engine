## 7. Yahoo Finance Limitations & Observations

### ✅ What Works Well:
- NSE stocks with `.NS` suffix download reliably
- Good historical data coverage (1-2+ years)
- OHLCV data format standard and consistent
- No API key required (public data)
- Handles dividend adjustments (Adj Close column)

### ⚠ Potential Limitations:
- **Rate limiting:** May occur with very frequent/bulk downloads (handled with configurable retries)
- **New stocks:** Newly IPO'd stocks may have limited history
- **Delisted stocks:** May have incomplete data in history
- **Data freshness:** EOD data, not real-time
- **Timezone:** Yahoo Finance uses UTC; IST conversion required

### 🔧 Mitigations in Place:
- Retry logic in `market_data.py` (configurable attempts)
- Data validation to catch missing/invalid data
- Graceful error handling for failed downloads
- Fallback to available data if some stocks fail
